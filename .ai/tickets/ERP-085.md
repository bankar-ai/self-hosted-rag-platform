# ERP-085 — Verify (and Fix if Needed) Mobile Browser Usability

Status: Backlog
Depends On: None
Category: Improvement

## Description

ERP-078 (responsive layout, 2026-09-19) added breakpoint-based behavior for narrow viewports —
the sidebar and source panel collapse into overlays below the `md` Tailwind breakpoint instead
of a fixed three-column layout — and ERP-079 (2026-09-19) added keyboard/focus-trap handling to
the source panel dialog. **Neither has ever been checked on a real phone or in an actual narrow
browser window.** Coverage so far is automated unit tests only (`vitest`/`jsdom`), which don't
exercise real touch interaction, real viewport/zoom behavior, or real mobile browser quirks
(iOS Safari's address-bar height changes, tap-target sizing, etc.).

The live app (`https://34-31-5-88.sslip.io` — see `gcp-deployment-tracker.md`) is reachable from
a phone's browser as-is (nothing blocks that), but whether it's actually *usable* there is the
open question this ticket exists to answer.

## Acceptance Criteria

- [ ] Load the live app on a real phone (or, at minimum, a browser devtools mobile emulation
      pass across a couple of common viewport widths) and walk through: opening/closing the
      sidebar overlay, sending a chat message, opening a citation's source panel, closing it
- [ ] Note any real usability problems found (broken layout, unreachable controls, text
      overflow, tap targets too small, etc.)
- [ ] Fix what's found, or split off separate follow-up tickets if the fixes are substantial
