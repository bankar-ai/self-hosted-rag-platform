# ERP-081 — Lazy-Load SourcePanel

Status: Backlog
Depends On: None
Category: Improvement

## Description

ERP-067's move to `react-markdown`/`rehype-raw`/`rehype-sanitize` for `SourcePanel`'s chunk-text
rendering nearly doubled the frontend bundle size (~285KB → ~580KB minified), flagged at the time
as a follow-up rather than a blocker. `SourcePanel` is only needed once a citation is actually
clicked, making it a good candidate for a lazy-loaded chunk.

## Acceptance Criteria

- [ ] `SourcePanel`'s import in `ChatPage.tsx` is wrapped in `React.lazy()` + `Suspense`
- [ ] `SourcePanel` (and its markdown-rendering dependencies) are split into a separate chunk not
      loaded until a citation is first clicked
- [ ] No behavior change to the panel itself; a brief loading state is acceptable while the chunk
      loads

## Notes

Frontend-only, mechanical. No new dependency.
