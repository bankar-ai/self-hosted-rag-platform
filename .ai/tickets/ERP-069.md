# ERP-069 — Anti-Hallucination: Don't Invent Dates/Facts Not In Context

Status: Backlog
Depends On: None
Category: Bug — confirmed hallucination

## Description

Live-verified: asked to explain a citation, the model stated a specific date ("July 21, 2026")
that does not appear anywhere in the source PDF (confirmed by reading the full document text).
The existing anti-hallucination system prompt (ERP-046/ERP-058) doesn't explicitly forbid
inventing specific facts/dates/numbers not present in context. See
`docs/superpowers/specs/2026-09-19-post-erp050-live-feedback-design.md` for the full design.

## Acceptance Criteria

- [ ] `SYSTEM_PROMPT` (`app/generation/prompt.py`) explicitly instructs the model never to
      state a specific date/number/fact unless it is verbatim present in the provided context,
      and to say so explicitly when a follow-up asks for a detail the context doesn't specify
- [ ] Live-reproduced: same PDF, same follow-up question, confirm the fixed prompt no longer
      asserts an unsupported date

## Notes

Not automatically unit-testable against a live LLM — verified via live reproduction only, same
calibration approach as ERP-046.
