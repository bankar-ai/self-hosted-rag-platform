# ERP-079 — Keyboard and ARIA Affordances on the Source Panel

Status: Done
Depends On: None
Category: Improvement

## Description

Live feedback from ERP-050: the source panel (opened by clicking a citation) has no keyboard or
screen-reader affordances — no focus trap, no `Escape`-to-close, no `role`/`aria-label`, and focus
does not return to the triggering citation marker on close.

## Acceptance Criteria

- [ ] Opening the source panel moves focus into it and traps focus within it while open
- [ ] `Escape` closes the panel
- [ ] The panel has an appropriate `role` (e.g. `dialog`) and `aria-label`
- [ ] Closing the panel (via `Escape`, a close control, or selecting a different citation) returns
      focus to the citation marker that triggered it

## Notes

Frontend-only, standard accessibility pattern.
