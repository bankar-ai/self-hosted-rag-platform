# ERP-078 — Responsive Layout for Chat + Source Panel on Narrow Viewports

Status: Done
Depends On: None
Category: Improvement

## Description

Live feedback from ERP-050: the three-pane layout (sidebar / chat / source panel) has no defined
behavior on narrow viewports. This needs a short design pass before implementation — likely
stacking panes or presenting the source panel as an overlay/drawer below some breakpoint, rather
than a one-line CSS fix.

## Acceptance Criteria

- [ ] A narrow-viewport strategy is chosen (stacked panes vs. overlay/drawer) and documented
- [ ] Sidebar, chat, and source panel all remain usable (no clipped/overflowing content, no
      horizontal scroll of the page body) at common narrow-viewport widths
- [ ] Existing desktop three-pane layout is unchanged

## Notes

Frontend-only. Design decision needed before implementation.
