# ERP-045 — Answer Feedback (Thumbs Up/Down)

Status: Backlog
Depends On: ERP-043

## Description

Surfaced during ERP-043's live UI review: there's no way for a user to signal whether a
generated answer was good or bad. Not implemented yet since it needs its own design pass before
it's buildable — open questions below aren't decided.

## Acceptance Criteria

- [ ] To be scoped via brainstorming — open questions: what feedback is captured (binary
      thumbs up/down vs. a comment field); where it's stored (new Postgres table, keyed to
      which conversation/message); whether it's surfaced anywhere (an admin view, or feeds the
      existing ERP-030 generation-evaluation harness as real user-labeled data rather than only
      LLM-judge scores); whether it's per-message or per-conversation

## Notes

Deliberately not bundled into ERP-043 — genuinely new scope, not a UI polish item. See
`docs/superpowers/specs/2026-09-16-web-ui-design.md`'s Future Follow-ups for the originating
discussion. Worth considering alongside ERP-030 (generation evaluation) when scoped, since
real user feedback could become a second signal alongside the LLM-judge scores that harness
already produces.
