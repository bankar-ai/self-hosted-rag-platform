# ERP-077 — Clickable Citation Markers Inside Bold Text

Status: Backlog
Depends On: None
Category: Bug

## Description

Live feedback from ERP-050: a clickable inline `[n]` citation marker in the answer text does not
become clickable when the marker falls inside a `**bold**` markdown span — the citation-marker
regex/rehype transform doesn't currently match across that boundary.

## Acceptance Criteria

- [ ] A `[n]` marker inside bold (or otherwise emphasized) markdown text is clickable and opens
      the source panel the same as a plain-text marker
- [ ] Existing plain-text marker behavior is unchanged

## Notes

Frontend-only, narrow fix in the message-rendering/citation-marker transform.
