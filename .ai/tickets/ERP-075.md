# ERP-075 — Copy Affordance for Full Conversation Turns and Sidebar Conversations

Status: Backlog
Depends On: None
Category: Improvement

## Description

`CopyButton` (ERP-068) currently covers a single assistant answer and the currently-open
conversation's full transcript (`ChatPage.tsx`'s "Copy conversation" action above the message
list). Two gaps remain, per live user feedback: there is no way to copy one Q+A turn (question +
its answer) together, and there is no way to copy a conversation's transcript from the sidebar
list without first opening it.

## Acceptance Criteria

- [ ] Each rendered Q+A turn in `ChatPage.tsx` gains a `CopyButton` that copies the paired user
      question and assistant answer together (not just the answer alone, which remains available)
- [ ] Each conversation row in `Sidebar.tsx`'s recent-conversations list gains a `CopyButton` that
      copies that conversation's full transcript without requiring it to be the open conversation
- [ ] No backend change — `CopyButton`'s existing `getText`-at-click-time contract is reused as-is

## Notes

Frontend-only. No new dependency.
