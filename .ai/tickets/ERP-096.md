# ERP-096 — Q&A Pair Disappears When Switching Tabs Mid-Stream

Status: Backlog
Depends On: None
Category: Bug

## Description

Live feedback (2026-09-24): if the user switches browser tabs while an answer is still
streaming, the in-progress Q&A pair disappears from view and only reappears once the answer
finishes generating. The user notes the same may happen on a page refresh mid-stream.

## Investigation So Far (code-only, not live-reproduced)

Read `ChatPage.tsx`'s `sendMessage` (the SSE streaming handler) — found nothing that explicitly
depends on tab visibility or `document.hidden`. Two candidate explanations, neither confirmed:

1. **Browser background-tab throttling**: Chrome (and others) throttle timers/rendering in
   backgrounded tabs for battery/performance reasons. If this is the cause, the "disappearance"
   may actually be a repaint delay, not a real state loss — the DOM update is just deferred
   until the tab regains focus. This would be expected browser behavior, not an app bug, and
   not something straightforwardly "fixable."
2. **Unstable React key**: the message list renders with `key={index}` (`ChatPage.tsx:397`)
   rather than a stable message id — a known React fragility (list identity can get confused
   across re-renders), though it's not obvious from reading the code alone how this would
   specifically manifest as "vanishes then reappears on tab switch."
